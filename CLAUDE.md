# Working in this repo

- Git: commit and push straight to `main`. No pull requests or feature branches unless asked.
- Never leave work only in the container: commit and push every change as soon as it is made, including
  generated results and any page or notes worth keeping (e.g. `explainer/`, `docs/`).
- Published artifacts: the Isodiv Explorer (https://claude.ai/artifact/K7Crudh3aj3bGwKTYNotHh) is built from
  `results/explorer.html`; the explainer (https://claude.ai/artifact/SnfTWDbcWUo58pDzsbyzZd) from
  `explainer/word-lists-to-dmax.html`. Republish to the same URLs after rebuilding.
